四类产物

<run_id>.full.jsonl

完整审计：prompt、token 数、组、前缀、seed、DP 路由、理论命中/水位

<run_id>.requests.jsonl

AISBench 最小输入：question/answer/max_tokens

<run_id>.manifest.json

复现入口：有效配置、SHA256、tokenizer 指纹、warmup 计划（不存 api_key 明文）

<run_id>.analysis.json

requested/effective/theoretical/actual 命中率、偏差、warnings

理论命中率 = Σ 命中 token / Σ 输入 token；实际命中率 = Σ(DP hit 增量) / Σ(DP query 增量)，token 加权。冷/热两种模式分别用 (group, DP) 与 group 作为缓存水位维度。

Extended Multimodal Generation Benchmarks
=========================================

* :doc:`VBench 1.0 <vbench>` evaluates the quality and semantic consistency of generated videos on GPU or NPU. The standard suite covers 16 metrics.
* :doc:`VABench <vabench>` evaluates 15 audio-video metrics on GPU from existing MP4s with audio. The guide covers the 778-prompt standard set and comparison with native VABench.
